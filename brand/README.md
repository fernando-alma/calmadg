# Recursos de marca CALMA

Archivos originales entregados por la diseñadora (PNG 1262 px y favicons SVG).
No se sirven en el sitio: son la fuente para generar las versiones web.

- `calma-*.png` — logotipo completo (blanco, negro, rosa, con punto rosa).
- `ca-*.png` — monograma "Ca." con "Estudio de diseño".
- `favicon-circular.svg` — favicon oficial (círculo negro). A partir de este diseño se generan
  `app/icon.png` (512 px) y `app/apple-icon.png` (180 px), recompuestos con el PNG en alta
  resolución porque el SVG trae una imagen interna de baja resolución.

Pendiente del manual de marca: logo en vector (SVG/AI/PDF) para nitidez perfecta en pantallas retina.
